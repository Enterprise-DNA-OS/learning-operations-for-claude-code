# budget-review

Compare approved budgets with labour and external commitments.

Run `npm run learning -- budget-review --json`. Read every returned row before summarising. Name the affected request or project and the evidence still needed. Never infer a result from missing data. For compliance, read docs/compliance.md and distinguish legal principles from local review rules. Nothing sends or changes status.
