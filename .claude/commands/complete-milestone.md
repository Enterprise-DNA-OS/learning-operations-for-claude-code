# complete-milestone

Read the milestone, inspect the evidence, and record the operator acceptance.

Run `npm run learning -- complete-milestone <milestone> --evidence=<reference> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
