# draft-brief

Read the request, projects, notes and any source export. Produce a brief for human review.

Run `npm run learning -- draft-brief <request> --json`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
