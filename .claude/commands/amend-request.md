# amend-request

Complete the owner, purpose, retention review date and safety brief before a decision.

Run `npm run learning -- amend-request <request> --file=<private-file.json> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
