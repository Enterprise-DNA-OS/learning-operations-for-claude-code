# draft-weekly-review

Read demand-review, capacity-plan and budget-review first. Then write a draft with impact and overdue exceptions. Present the result in chat.

Run `npm run learning -- draft-weekly-review --json`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
