# decide-request

Read the request and compliance checks. Record the explicit operator decision and reason.

Run `npm run learning -- decide-request <request> --status=<status> --reason=<reason> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
