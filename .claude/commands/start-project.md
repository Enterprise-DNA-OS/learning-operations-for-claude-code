# start-project

Read the approved request and plan, then record the operator decision to start.

Run `npm run learning -- start-project <project> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
