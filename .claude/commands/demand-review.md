# demand-review

Prepare the weekly demand triage in priority and waiting-time order.

Run `npm run learning -- demand-review --json`. Read every returned row before summarising. Name the affected request or project and the evidence still needed. Never infer a result from missing data. For compliance, read docs/compliance.md and distinguish legal principles from local review rules. Nothing sends or changes status.
