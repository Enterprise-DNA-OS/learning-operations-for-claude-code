# complete-project

Read milestones and evidence first. Complete only an active project whose delivery has been accepted.

Run `npm run learning -- complete-project <project> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
