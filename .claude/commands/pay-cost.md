# pay-cost

Record a payment already made elsewhere using its evidence. This command transfers no money.

Run `npm run learning -- pay-cost <cost> --evidence=<receipt-reference> --actor=<operator>`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
