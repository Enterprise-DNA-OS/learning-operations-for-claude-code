# add

Read docs/cli.md. Write the operator-approved fields to a private JSON file, then add one record. Do not invent evidence or people.

Run `npm run learning -- add <entity> --file=<private-file.json> --actor=<operator> --json`. Actor labels record the operator statement and are not authentication. Use exact codes if a name is ambiguous. Drafts stay in `drafts/` and never send.
