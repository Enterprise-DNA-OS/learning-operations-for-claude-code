# Why there is no front end

A learning operations manager repeats a small set of decisions: what training demand to accept, who can do the work, what it will cost, what is late and whether the outcome was measured. This desk stores that evidence and answers those questions through one CLI and coding-agent recipes.

Read-only HTML reports show capacity, costs and evidence. Training briefs and investment reviews print from the same records. There is no server or write button.

A full application supplies request forms, visual scheduling, mobile access, notifications and permissioned collaboration. This base has none of those. Local storage can work without a network after installation, but the coding agent may need a connection; there is no offline mobile synchronisation. Cognota also offers services and marketplace access, which a local database does not replace.

The base suits a trusted operator who can review records through a coding agent. It is not a course player, a learning content authoring tool or a learner portal. Enterprise DNA scopes team screens, connections and operations in the customised version. Use the reports for visibility and the agent for approved actions.
